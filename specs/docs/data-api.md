# Data API

v1

The Data API provides HTTP/JSON REST endpoints for reading and writing data to the
Palo Alto Networks Cortex XCOR system.

Use this link to download the raw Swagger specification:
[Download](/openapi/api_v1_data_swagger.json)

### Security

#### API Key

##### Cortex XCOR API token

An API key is a token that you provide when making API calls. Include the token in a header parameter called
`API-Token`
.

Example:
`API-Token: 123`
